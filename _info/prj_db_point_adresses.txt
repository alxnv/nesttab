создать базу данных адресов и координат различных пунктов выдачи заказов (для продажи интернет магазинам, с обновлением в реальном времени)

регистрируется фирма создатель магазинов, у нее есть инет магазины с идентификаторами, она сама их добавляет

создается основная база, в виде sql скрипта, и генерируются базы по периодам
 основную базу можно загрузить куда-нибудь на хостинг (яндекс диск например)
каждому обновлению соответствует номер
при регистрации инет магазина указывается http(s) адрес, по которому нужно обращаться для обновления данных в магазине

хостинг проекта надо сделать выделенный, (единоличный), с возможностью постоянного запуска скриптов

магазин по крону обращается на хостинг проекта, при обращении его ip адрес проверяется на соответствие домену сайта адреса указанного
 при регистрации, затем в течении дня происходит обращения с хостинга проекта на сайт магазина для обновления, если не успели за день,
  то обращения не будет
  
также ведется база городов России с идентификаторами

запрашивается набор данных указанный, в начале будет 3 набора:
 города, данные основных фирм пунктов приема заказов, данные дополнительных фирм пункта приема заказов
 
предусмотреть независимый от типа sql набор данных (mysql, oracle, ...)

каждая порция обновлений разбивается на куски (data1.sql, ...)

предусмотреть защиту от спама и ддос-атак
